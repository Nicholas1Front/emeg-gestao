# 📊 EMEG — Sistema de Gestão em Planilha

> Uma solução de gestão empresarial desenvolvida em planilha para centralizar informações financeiras, operacionais e administrativas da empresa.

---

## 📌 Sobre o projeto

O **EMEG — Sistema de Gestão em Planilha** foi desenvolvido com o objetivo de organizar e centralizar diferentes processos da empresa em um único ambiente.

A solução reúne ferramentas para **controle financeiro, acompanhamento de serviços, gestão de funcionários, agenda e visualização de indicadores**, proporcionando uma visão mais organizada das operações.

O projeto foi desenvolvido utilizando **LibreOffice Calc**, explorando recursos de organização de dados, fórmulas, validações, automações e dashboards.

---

## 🚀 Funcionalidades

### 💰 Gestão Financeira

* Controle de contas mensais
* Registro de entradas e saídas
* Fluxo de caixa
* Organização dos lançamentos financeiros
* Dashboard para acompanhamento dos dados

### 👥 Gestão de Funcionários

* Registro de funcionários
* Controle de informações relacionadas à equipe
* Lançamentos e acompanhamento das movimentações

### 🔧 Gestão de Serviços

* Registro de serviços
* Organização dos lançamentos
* Acompanhamento das informações dos serviços
* Dashboard para visualização dos dados

### 📅 Agenda

* Organização de compromissos e atividades
* Centralização das informações em um único ambiente

### ⚙️ Configurações

* Área centralizada para configurações utilizadas pela planilha
* Estrutura organizada para facilitar manutenção e utilização

## 🗂️ Estrutura da planilha

A solução é dividida em diferentes módulos:

| Aba                    | Função                                    |
| ---------------------- | ----------------------------------------- |
| `HOME`                 | Página inicial e navegação                |
| `CONFIG`               | Configurações do sistema                  |
| `CONT_MENS`            | Controle de contas mensais                |
| `FL_CAIXA_LANÇAMENTOS` | Lançamentos do fluxo de caixa             |
| `FL_CAIXA_DASHBOARD`   | Dashboard financeiro                      |
| `FUNC_LANÇAMENTOS`     | Lançamentos relacionados aos funcionários |
| `SERV_LANÇAMENTOS`     | Controle de serviços                      |
| `SERV_DASHBOARD`       | Dashboard de serviços                     |
| `AGENDA`               | Organização de atividades e compromissos  |

## 🎯 Objetivo

O principal objetivo do projeto foi transformar uma planilha tradicional em uma **ferramenta centralizada de apoio à gestão**, facilitando o registro, organização e acompanhamento das informações da empresa.

Além da aplicação prática, o projeto também representa um exercício de **análise de processos, organização de dados, criação de indicadores e desenvolvimento de soluções para problemas reais**.
